# Corresponding source

If Alpha 2 is accepted and locally packaged, its binary archive is intended to
be accompanied by:

- `Proton-RTSP-Wayland-GE-Alpha2-source.tar.gz`
- `Proton-RTSP-Wayland-GE-Alpha2-source.tar.gz.sha512sum`

The companion archive is generated by
`scripts/package-corresponding-source.sh`. It contains the fully prepared RTSP
Proton source tree, the applied Wine tree, the 105 active GE format-patch files,
the pinned GE WineOpenXR repair, its one-line RTSP makedep adapter, dependency
sources and license files, the X11 locale data, the xrandr source archive,
project build scripts, and external snapshots used by the speech and Xalia
payloads.

The `distribution/` portion is exported only from a clean, tracked Git
revision; packaging refuses tracked changes and non-ignored untracked files,
and ignored workspace data is never copied. The prepared Proton tree is
assembled from tracked Git files plus the explicitly pinned locale,
libxml2, libxkbcommon, Wayland Protocols, and build-time archives. Optional
Cargo registry sources or Git checkouts enter the package only when their
directories are explicitly supplied to the packaging command.

The GE inputs come from development snapshot
`9fad3bbe270409e67a8d2f4d123afc73d848306a`, selected from `master` on
2026-07-13. They are not GE-Proton11-2 release inputs. Packaging is disabled by
default with `PACKAGE_RELEASE=0`; this document does not authorize publication.

  the earlier mutable branch archive is historical evidence, not an Alpha 2
  input and not part of the corresponding-source package;
- eSpeak NG: commit `0f65aa301e0d6bae5e172cc74197d32a6182200f`;

  `e26a111c1b90301e37475a4dfb6f5ce47447d677`;

  `e2c94a40f68f63660cc06405a641bc4e5a2e9b9320b9608e01a21feb6f6709c5`;
- Wine Gecko 2.47.4 x86 and x86_64 archive SHA-256 values

The Xalia ZIP hash is enforced after download and before extraction. Resume
validation also verifies every cached Gecko, Mono, Xalia, and xrandr archive;
local source packaging verifies the Xalia archive again before copying it into
`external/download-archives/`. The prepared Wine content is additionally locked
by tree object `77ad524530fb09557af260ae6e50204bc42141c2`.

See `NOTICE.md` for the complete pinned Proton, Wine, GE, and dependency
revisions. The pinned inputs support source reconstruction and review, but the
current container/toolchain and archive timestamps are not sufficiently pinned
to promise bit-identical binary reproduction.
