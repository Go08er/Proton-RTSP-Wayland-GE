# Corresponding source

Every binary release is intended to be accompanied by:

- `Proton-RTSP-11.1-Wayland-GE-source.tar.gz`
- `Proton-RTSP-11.1-Wayland-GE-source.tar.gz.sha512sum`

The companion archive is generated by
`scripts/package-corresponding-source.sh`. It contains the fully prepared RTSP
Proton source tree, the applied Wine tree, the 101 original GE format-patch
files, dependency sources and license files, the X11 locale data, the xrandr
source archive, project build scripts, and external snapshots used by the
speech and Xalia payloads.

Important external snapshots include:

- piper-phonemize: commit `5ecbb9b59abcffe03a9775ae82491c9ac5037f4d`;
  the original branch-named build input had SHA-256
  `728800cd310c64e6b6877866161b32ff0dc2d9c52ebdc54281fa21e448d2adef`,
  and the staged immutable-commit archive has SHA-256
  `cd89aff6c3728776ffbf382bd6574876cc67d13402140fc5e3ec8c2bc813335f`;
  both archives are retained under `external/download-archives/` so the
  actually consumed input and the immutable replacement are independently
  reviewable;
- eSpeak NG: commit `0f65aa301e0d6bae5e172cc74197d32a6182200f`;
- Xalia 0.4.9: commit `6d946216c29052c29c660ad4cac950a6bd08a2b4`;
- Xalia SDL3-CS submodule: commit
  `e26a111c1b90301e37475a4dfb6f5ce47447d677`;
- Xalia binary input archive SHA-256
  `e2c94a40f68f63660cc06405a641bc4e5a2e9b9320b9608e01a21feb6f6709c5`;
- xrandr 1.5.4 source archive SHA-256
  `2cafccb2aaf2491a4068676117a0d4f90ab307724b96fffc54cd1da953779400`.

See `NOTICE.md` for the complete pinned Proton, Wine, GE, and dependency
revisions. The pinned inputs support source reconstruction and review, but the
current container/toolchain and archive timestamps are not sufficiently pinned
to promise bit-identical binary reproduction.
